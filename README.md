# set-yum-priority.sh

有効になっている DNF リポジトリの優先順位を対話形式で設定する Bash スクリプトです。設定済みの優先順位を表示することもできます。スクリプト名に yum が含まれますが、リポジトリ管理には `dnf` を使用します。

## 動作環境

- Bash
- DNF がインストールされ、`rpm` から検出できること
- `dnf config-manager` が利用できること
- root 権限で実行すること
- `/root/.bash_profile` または `/root/.profile` が存在し、読み込み可能であること

設定変更時は、DNF の設定情報から取得したリポジトリ設定ディレクトリを使います。DNF 5 の場合は、存在すれば `/etc/dnf/repos.override.d` と `/usr/share/dnf5/repos.override.d` もバックアップ対象になります。

## 使い方

```bash
sudo /path/to/set-yum-priority.sh -e
```

実行すると、有効なリポジトリ ID が表示され、各リポジトリについて優先順位の入力を求められます。値は `1`〜`99` の整数を指定してください。入力値が範囲外または数値でない場合は、再入力になります。

優先順位は小さい値ほど高くなります。値の間隔を空けておくと、後から別のリポジトリを間に設定しやすくなります。たとえば、基本リポジトリに `1`、EPEL に `5` を指定できます。

設定済みの値を確認するには、次のように実行します。

```bash
sudo /path/to/set-yum-priority.sh -l
```

`-l` は設定を変更せず、対話入力も行いません。リポジトリファイルに記載された値と、DNF コマンドから取得した値を表示します。値が設定されていない場合、該当する優先順位の行は表示されません。

## オプション

| オプション | 動作 |
| --- | --- |
| `-e` | 有効なリポジトリごとに優先順位を入力し、DNF の設定に反映します。 |
| `-l` | 設定済みの優先順位を表示します。 |

どちらかのオプションを指定してください。`-e` と `-l` の両方を指定した場合は、表示のみを行い、設定変更は行いません。

## バックアップと変更内容

`-e` の実行では、設定変更の前に対象のリポジトリ設定ディレクトリを次の形式で圧縮バックアップします。

```text
/etc/set-yum-priority.sh_YYYYMMDD-HHMMSS_PID.tar.xz
```

その後、各有効リポジトリについて入力された優先順位を `dnf config-manager` で設定します。既存の優先順位は、入力した値で置き換えられます。

## 補足

- 多重起動を防ぐため、`/tmp/set-yum-priority.sh.lock` をロックとして使用します。
- 一時ファイルは `/tmp` に作成し、終了時に削除します。
- DNF からリポジトリ設定ディレクトリを取得できない場合や、バックアップに失敗した場合は設定を続行しません。
